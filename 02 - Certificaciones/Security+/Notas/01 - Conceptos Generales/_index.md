# Dominio 1 — Conceptos Generales de Seguridad

> [!abstract] Pesa **12%** del examen. Base teórica de toda la seguridad.

## Peso en el examen

| Formato | Cantidad aprox |
|---------|---------------|
| Preguntas totales del dominio | ~10-11 |
| Peso relativo | 12% |

## Objetivos del dominio (sacados de los exam objectives)

- [ ] **1.1** — Comparar y contrastar los tipos de controles de seguridad
- [ ] **1.2** — Resumir los conceptos fundamentales de seguridad (CIA, AAA, etc.)
- [ ] **1.3** — Explicar los principios de gestión de cambios
- [ ] **1.4** — Explicar la importancia de la automatización y orquestación en seguridad

## Conceptos clave para documentar acá

- [ ] **Triada CIA** — Confidencialidad, Integridad, Disponibilidad. Ejemplo de cada una.
- [ ] **AAA** — Authentication, Authorization, Accounting. Diferencia entre cada una.
- [ ] **Tipos de controles** — Preventivo / Detective / Disuasivo / Compensatorio / Físico / Técnico / Administrativo. Saber clasificar.
- [ ] **Principios de seguridad** — Mínimo privilegio, defensa en profundidad, segregación de funciones, zero trust (concepto general)
- [ ] **Gestión de cambios** — Cambio, parche, mantenimiento, solicitud de cambio

# 🎓 Certificaciones

Apuntes de estudio organizados por certificación. Cada carpeta representa un examen objetivo.

## Estructura

| Carpeta | Certificación |
|---------|---------------|
| `Security+/` | CompTIA Security+ (SY0-701) — **en progreso** |
| `eJPT/` | eLearnSecurity Junior Penetration Tester |
| `OSCP/` | OffSec Certified Professional |
| `PNPT/` | Practical Network Penetration Tester |

## Cómo usar esta sección

- **Cada carpeta es independiente**, con sus propias notas y recursos por certificación.
- Crea sub-carpetas dentro de cada cert si lo necesitas: `Notas/`, `Laboratorio/`, `Recursos/`.
- Usa la plantilla [[_Plantillas/Tema Teorico]] para conceptos y [[_Plantillas/Herramienta o Comando]] para técnicas específicas del examen.
- Etiqueta las notas con `#cert/eJPT`, `#cert/OSCP`, etc.
- Enlaza a [[01 - Fundamentos/_index|Fundamentos]] y [[03 - Herramientas/_index|Herramientas]] para conectar conceptos.

## Notas

> [!tip] Si una certificación comparte temas con otra, escribe la nota en **Fundamentos** y enlázala desde acá. Evita duplicar contenido.
